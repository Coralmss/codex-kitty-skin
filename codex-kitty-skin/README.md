# 🎀 草莓奶油 · Codex Kitty Skin

把 Codex 换成奶油粉、草莓和 Hello Kitty 的温柔小房间。背景、玫瑰粉按钮、白色发送图标、柔和输入框与简洁项目选择样式一起提供，并附可选毛绒 Kitty 宠物。

![主题背景](preview.png)

## 让你的 AI 帮你安装

复制这段话给能操作电脑的 AI：

> 请帮我安装 https://github.com/Coralmss/codex-kitty-skin 的草莓奶油皮肤。先阅读 AI_INSTALL.md，检查系统和现有安装，解释本地调试方式，按说明安装并验证实际窗口效果。我也想安装附带的 Kitty 宠物。不要覆盖我已有的其他皮肤或修改官方应用文件。

也可以通过 GitHub 绿色 **Code → Download ZIP** 下载，解压后按 [安装说明](AI_INSTALL.md) 操作。无需 GitHub 登录、API Key 或订阅本项目。

## 包含什么

- 完整背景和主题包，不依赖原作者电脑上的路径。
- 固定版本的 Dream Skin 开源引擎源码及配色修补，打包在 `payload.zip` 中；解压即可阅读。
- 安装前检查、官方应用签名验证、配置备份与恢复原外观入口。
- 可选 Kitty 宠物（安装后需在 Codex 设置中选择）。

![Kitty 宠物](pet-preview.gif)

首版安装器支持 **macOS**。样式在 Codex **26.908.40834** 上验证过；不同版本、窗口尺寸可能有差异，应用更新后可能需要适配。新电脑完整安装流程尚未在另一台实体 Mac 上验证。当前安装器会保护已有 Dream Skin 安装，遇到已有版本时停止，由 AI 检查迁移。

本项目只改变界面展示，不包含任何聊天、项目、账号配置或官方 Codex 程序。通过本地调试连接应用，后续从 `Open Kitty.command` 启动。详情、兼容性与恢复方法见安装说明。
